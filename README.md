# 网站界面设计与验收

一个可供 Codex 使用的网站界面开发 skill。根据当前网站的用户任务选择组件、补齐交互状态，并按需输出 PNG、实现和对照真实页面验收；不限定颜色、字号或视觉风格。

## 内容

- [SKILL.md](SKILL.md)：技能入口、适用范围与执行流程。
- [通用组件、状态和验收规则](references/web-ui.md)：导航、菜单、详情面板、页签、表单与图表的选择条件及可观察验收。
- [变更契约模板](assets/ui-contract.md)：记录本次规格来源、状态与测试证据。
- 其余 references 文件：以[我曾开发的访谈分析工作台](https://github.com/Drifter-LP/interview-analysis-workbench)为例，保留当时的具体取舍。不是其他网站的默认规范，也不保证与案例仓库最新版本一致。

## 使用

下载本仓库，将文件放入 Codex 技能目录下的 `workbench-ui-workflow` 文件夹，确保该文件夹内直接包含 `SKILL.md`、`agents`、`references` 和 `assets`。

可用这样的请求调用：

> 使用 $workbench-ui-workflow 改进这个网站。先判断本次应该用什么组件，列出相关交互状态；不要套用案例项目的颜色和尺寸。先输出 PNG 供确认，暂不改业务代码。

如已确认设计，可明确要求实现并验收。PNG 确认、代码实现、模拟测试和线上验证是不同交付状态，应分别说明。

## 验证边界

本技能已检查格式和内部文档链接。它不是网站运行代码；格式通过不代表采用它后的网站已通过功能、无障碍或安全审计。
