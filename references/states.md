# 完整状态与生命周期

这里的“不变量/验收要求”为后续开发规则，不表示历史所有模块已经满足。对不适用状态标 N/A 并说明原因，不为凑清单添加无用功能。

## 1. 所有组件的状态表

在写代码前，为实际涉及的组件补齐以下表格。

| 组件 | 必测状态 | 不变量 |
| --- | --- | --- |
| 侧栏 | 展开、收起、当前组、hover、键盘打开、指针跨到菜单、窄屏 | 收起不露残字；路由和图标含义不变 |
| 短菜单 | 打开、关闭、选中、禁用、危险、子菜单、边缘翻转 | 不越界、不遮断到子菜单的路径、动作仅执行一次 |
| 抽屉 | 未开、进入中、已开、退出中、请求未完成时关闭、再次打开 | 退出完成前不卸载；关闭不丢工作区输入；晚到请求不复活已关界面 |
| 页签 | 初始、向前、向后、快速反复切换、相同页签重复点击、切换中离页 | 最后一次选择有效；不克隆编辑器；不重置草稿 |
| 输入/提交 | 空、合法、非法、长值、焦点、提交中、失败、成功 | 错误贴近字段；输入和业务请求不因视觉更新丢失或重复 |
| 数据区 | 未加载、加载、成功零值、成功有值、空资料、失败、刷新、过期响应 | 未知不等于0；旧请求不覆盖新筛选 |
| 权限界面 | 未登录、普通成员、管理员、会话过期、账号切换 | 角色由真实会话确定，后端校验不可省略 |

## 2. 短菜单的交互合同

- 触发器点击/键盘均能开，设置 aria-expanded 与 aria-controls；选择类菜单同步选中状态。不要只给图标绑定事件而让文字区域失效。
- 鼠标进入同一菜单不关闭；点击外部关闭；Escape 关闭当前最内层菜单，焦点回原触发器。
- 上下键移动可用项，Home/End 到首末；禁用项不可执行；嵌套菜单右键进入/左键返回。这里“右键/左键”指 ArrowRight/ArrowLeft，不是鼠标按键。
- 选择叶子操作后关闭菜单，并保留操作自身的焦点处理；例如选择“重命名”弹出输入框时，不要把焦点又抢回更多按钮。
- 关闭不是全局粗暴 remove 所有浮层。用户打开编辑面板或输入框后，短菜单清理不能误关它们。
- 仅hover可打开不够：触摸点击、Enter/Space/方向键至少提供可用替代。已有组件不是标准ARIA menu时，不机械叠加role，确保角色与键盘模型匹配。

## 3. 抽屉的状态机与动效

状态序列：closed → opening → open → closing → closed。

I：右侧进入220ms，translateX(100%)→0，缓动cubic-bezier(.2,.75,.25,1)；退出180ms，从当前视觉位置→100%，缓动cubic-bezier(.4,0,.8,.3)。这些是工作台基线，新项目可调整，但进入/退出都应连续。

执行规则：

1. 记录触发器和必要的滚动/输入状态，再打开modal；原页面和编辑器不重建。
2. 进入途中收到关闭，取消进入动画，从当前实际位置开始退出，不瞬移回起点。
3. 重复关闭只执行一次；真正close/unmount/remove发生在退出完成后，而不是用户点×的当下。
4. 以generation/request token丢弃过期回调，关闭后网络返回不得重开抽屉或写入不存在的面板。
5. ×、Escape、遮罩关闭走同一条状态机。内部点击不当作遮罩点击；有未保存内容，先走脏状态策略。
6. Escape先关内部菜单，再关外层抽屉；不能一次按键同时关闭两层。
7. 关闭后焦点回仍存在的触发器，preventScroll避免页面跳动；触发器已移除时回合理位置，不能指向失效节点。
8. 保证打开时焦点在面板内；关闭后键盘可继续原任务；滚动长抽屉时不把整页一起滚动。不要以手工tabindex覆盖浏览器原生dialog已有能力。
9. prefers-reduced-motion时直接切换最终状态，不用偷偷延长淡出；业务关闭和焦点恢复仍必须执行。

## 4. 同页切换与异步请求

H：切换时内容滑出/滑入，而不是硬出现/消失；页面外框、侧栏、标题和工具栏不参与横向移动。

I：工作台页签内容退出100ms、进入100ms；水平位移16px；向右选择时旧内容左出、新内容右入，向左选择反向；选中下划线约200ms连续移动。总时长约200ms，不另叠一套重复入场动画。

- 只在主动换页签时触发。不在初始渲染、输入、轮询、图表重绘、数据更新时触发。
- 相同页签正常重复点击不播放；有待完成切换时选择当前页，需取消待切换，不能让旧回调再切走。
- 每个内容区维持当前动画和取消标识。离开页面时取消未完成切换，避免100ms后又把人拉回旧页面。
- 原生DOM保持同一身份；不得为了动画克隆contenteditable、密码框、canvas或保存状态。进出动画不授权改变原来的保存/丢弃草稿策略。
- 筛选器默认只更新数据，不把每次模型/日期切换做成整页滑动。若用户另有要求，单独定义局部动效。
- 异步查询必须考虑A慢B快：用户选A后马上选B，即使A最后返回也只显示B。加载时禁用合理控件或保留切换能力，但清楚标示过渡数据所属范围。
- 不承诺页面标题区高度恒定：不同任务可能有不同工具行；验收“外框不横移”和“自然布局高度变化”需分开。若用户要求完全不跳动，再设计稳定高度，不用动画掩盖结构变动。

## 5. 原文核查状态

- 显示当前待核查发现和证据，不能只截/显示一段无上下文引文。
- 原文只读，保留研究者编辑区；默认核查不自动修改研究结论。
- 精确定位依赖当前来源、版本/hash、offset及引文匹配；多处相同引文不随意选一处当作确认匹配。
- 原文读取失败：显示“保存的引文/暂未读取原文”状态，不伪装成已定位原文；重复匹配、版本不一致各有提示。
- 加载中关闭后不重新弹出；不因返回原文丢失筛选、草稿或原滚动上下文。

## 6. 长文本、窄屏、错误与草稿

- 用最长可信用户名、中文标题、英文模型名、长邀请链接测试。菜单可增宽/ellipsis配完整title，输入和错误说明可换行；关键结果不得静默截断。
- 至少验收桌面1440×900与窄屏390×844；若有获批图片，另加其精确视口；这些是测试基线，不代表本来页面只支持这两个尺寸。
- 200%缩放是建议的补充检查；触摸目标小于44px的历史紧凑组件不要声称已满足所有移动可用性目标，可扩大命中区而不改变视觉尺寸。
- 所有API错误返回用户能理解的原因和下一步；不把原始堆栈、密钥、邀请令牌写进公开提示或截图。
- 表单失败后保留值，按钮重新可用；刷新额度和切换“我的账号/成员管理”不重建正在填写的邀请表单。显式“返回/重置”是否丢弃草稿另行说明，不暗中改变。

## 7. 如何测试而非只描述

每个状态至少指定一个可观察断言。例如：

- 退出开始50ms后：dialog.open仍为true，横向transform正在变化；退出完成后才false。
- 模拟慢响应，打开原文后立即关闭；返回后抽屉数量仍为0。
- 打开菜单按Escape：菜单不可见，activeElement为触发器；外层抽屉仍开。
- 页签A→B→A快速连点后：最终激活A、没有存活的过期动画，草稿值和节点身份不变。
- 日期30天和本人范围：请求参数、标题、总数、横轴都属于同一组合；mock A慢B快可稳定复现竞态。
- 非法用户名：发出的邀请请求数为0；服务端错误后重试可发出一次新请求；成功后不重复创建账号。

测试可以使用隔离数据和模拟接口，但要明确它验证的是前端交互/契约，不是假称验证了生产数据库或模型结果。
