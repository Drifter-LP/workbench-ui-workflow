# 从任务选组件，从行为定验收

## 一、先问用户会做什么，再问组件长什么样

| 情况 | 选择与取舍 | 可以当场检查什么 |
| --- | --- | --- |
| 跨栏目导航 | 要收藏、分享或靠浏览器返回的目标，用真实链接。栏目少且低频，顶栏或正文链接足够；频繁跨模块且需要随时定位，才考虑常驻侧栏。不要给只有一篇文章的页面设计折叠侧栏。 | 直接打开子页面能识别当前位置；返回不丢阅读位置。若有收起态，不出现裁碎的文字；陌生图标有可访问名称及可见解释，触屏不依赖悬浮。 |
| 条目旁的更多操作 | 少量即时命令用锚定菜单；主任务不要只藏在“更多”。需要填写字段的操作，点击后进入表单，不在小菜单里继续塞字段。 | 从触发器移动到菜单不中途消失；靠边时翻转或避让；点击、键盘均可进入。Esc 先关最内层并返回合适焦点。 |
| 详情、编辑、确认 | 要对照原文或列表且任务短，用非模态侧面板或行内展开；要连续多步、分享地址或手机全宽阅读，用独立页；必须先作决定才能继续，才用模态框。能撤销的低风险操作优先直接执行并提供撤销。 | 打开前先规定背景能否操作。关闭后保留原列表筛选和位置。有未提交修改时明确保留、保存还是确认放弃，不能点空白就静默丢稿。 |
| 切换视图与筛选 | 同一对象下的互斥视图可用页签；仅改变相邻图表范围的少量选项用紧邻标题的分段控件；选项多或文字长时用选择器。可组合条件用复选，不伪装成单选胶囊。 | 切换前后标题、单位和数据范围一致；键盘焦点不等于当前选中；快速 A→B→A 后仍显示 A，不被 B 的晚到结果覆盖。 |
| 表单与账号 | 短表单就近完成；多步注册、外部认证回跳等优先独立入口。登录浮层仅在保留上下文确有价值时使用，未登录背景只能显示公开内容。 | 标签不依赖占位字；在字段附近解释怎么改；提交中防重复，失败保留可安全保留的输入。分别测试匿名、普通、管理身份。隐藏按钮不是权限校验。 |
| 指标与图表 | 看当前值可只显示数字；看时间变化才用趋势图。空间不足以读清轴、单位、长标签时改为上下排或表格，不一律固定列数。仅当有确定上限时显示完成比例。 | 区分真实零值、尚在加载、无记录、请求失败；换时间范围时总数与序列使用同一口径。明确无上限时不要让空轨道看起来像余额为零。 |
| 文字、强调与选中 | 先区分“读什么”“去哪儿”“现在在哪儿”。标题用层级，操作用按钮或链接，选中态用位置稳定的标记、描边、字重或文字；可叠加项目强调色，不要求所有强调都用品牌色。 | 拿掉颜色后仍能找到当前项；悬浮到旁边一项时不误以为已切换；键盘焦点可见。正文放入真实长句、长名字和放大字体检查，不靠缩小全站字号救一个控件。 |

## 二、静态外观不是完整状态

给每个有风险的操作写一句可重现的合同：**起点 → 操作 → 等待时看到什么 → 成功或失败后数据、焦点和界面分别在哪里**。不要机械地给静态标题列十几个状态。

- 打开与收入：仅在动效帮助定位时采用。若采用，关闭要从当前位置退回，结束后才移除；开到一半按 Esc、关到一半重开，各试一次。减少动态效果时直接到终态，焦点与数据结果相同。
- 读取与筛选：用慢响应切换两次条件，确认只展示最后选择的结果。初次加载不显示假零；刷新旧数据时标明正在更新；失败保留重试入口。后台刷新不抢焦点、不触发一次新的切页动画。
- 写入：至少走非法输入、重复点击、服务拒绝、修改后重试、成功返回五条路径中适用的部分。无法确认写入结果时不要自动重发有副作用的请求。
- 布局边界：选最容易失败的一组内容或设备，例如最长菜单项、手机软键盘、仅键盘操作，或已有草稿时后退。把预期结果写清，不能用“响应式正常”代替观察。

## 三、PNG 确认与对照验收

1. **设计前约定比什么。** 明确要改和不动的区域、实际宿主页面和参照控件。区分“左边缘与输入框对齐”（关系约束）、“必须使用原色”（精确约束）、“更紧凑”（需结合可读性判断）。只要 PNG 就止于 PNG。
2. **用能复现的内容出图。** 选择能影响决定的状态：例如一个菜单打开的窄屏比三张相似空页面更有用。记录视口、缩放、字体、角色和示例数据；导出并打开实际 PNG 检查。图中无真实姓名、密钥或邀请令牌。展示不出的行为用一句说明，不暗示图片演示了动效。
3. **确认的对象是某一版图和范围。** 标明对应文件及已选方案；用户只改一个位置，就保留其他已确认关系。已有明确要求的小修不强行追加一次设计审批。
4. **实现后用相同条件截图。** 先比较结构、文字和状态，再比较锚点、边距、换行和颜色。用叠图或实际页面尺寸定位偏差，不通过拉伸截图制造一致。遇到字体或像素密度差异先记录环境；对文字可见区域的要求不能用外框居中代替。
5. **视觉和行为分别签收。** 每项记录“预期｜实际｜证据｜通过、未通过或未测”。至少真实操作本次的主路径和一个相关失败或边界路径；改了首屏就查冷刷新，改了浮层就查关闭和焦点。模拟数据通过不等于后端权限通过，本机通过不等于线上通过。

例如，活动报名页要求“手机上容易报名”：先用长活动名、截止日期和报名入口检查窄屏层级，再走“提交失败→保留填写→重试成功”。即使桌面 PNG 完全一致，只要重试会生成两份报名，本次仍不能报验收通过。
